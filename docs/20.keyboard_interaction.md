# keyboard interactions:

- type & tab -> are not part of the keyboard api
  type() -> utility api (Do this action on this element)
  tab -> convenience api (Do what the user would naturally do next, You don’t say where to go — the browser decides.)

---

==> utility apis
1- type(): typing into input element
2- clear(): clear editable element
3- selectOptions() / deselectOption():
select or deselect element from dropdown or multiple select for checkbox
select the label or the value for selection

==> clipboard apis
