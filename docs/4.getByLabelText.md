## getByLabelText

search for the label that matches the given text & find the element that label

works for label(<label htmlFor="name"> </label>) &
wrapper label(<label> <checkbox></checkbox></label>)

=> in case 2 components have the same label: use options

# options

=> selector
Limits the search to specific element types (e.g., 'input', 'textarea', 'select').

=> exact
When false, allows partial or case-insensitive matching. Default: true.

=> normalizer
modify the text before matching (e.g., trim spaces).
