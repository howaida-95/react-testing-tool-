# getByRole Documentation

## Overview

`getByRole` is the most recommended query method in React Testing Library because it finds elements based on their accessibility role, which closely mirrors how users interact with your application. It's user-focused and promotes accessible design.

## Syntax

```javascript
getByRole(role, options);
```

## Parameters

- **role** (string): The accessibility role to search for
- **options** (object, optional): Additional options to refine the search

## Common Roles

### Interactive Elements

- `button` - Buttons, input[type="button"], input[type="submit"], input[type="reset"]
- `link` - Anchor tags (`<a>`)
- `textbox` - Input fields (text, email, password, etc.)
- `checkbox` - Checkbox inputs
- `radio` - Radio button inputs
- `combobox` - Select dropdowns
- `slider` - Range inputs
- `switch` - Toggle switches

### Content Elements

- `heading` - h1, h2, h3, h4, h5, h6 elements
- `paragraph` - p elements
- `list` - ul, ol elements
- `listitem` - li elements
- `table` - table elements
- `cell` - td, th elements
- `row` - tr elements
- `img` - Image elements
- `form` - form elements

## Options Object

```javascript
{
  name?: string | RegExp,        // Accessible name (aria-label, aria-labelledby, etc.)
  hidden?: boolean,              // Include hidden elements (default: false)
  selected?: boolean,            // For radio/checkbox: selected state
  checked?: boolean,             // For checkbox: checked state
  pressed?: boolean,             // For button: pressed state
  expanded?: boolean,            // For elements with expand/collapse
  level?: number,                // For headings: h1=1, h2=2, etc.
  description?: string | RegExp  // aria-describedby content
}
```

## Examples

### Basic Usage

```javascript
// Find a button
const button = getByRole("button");

// Find a heading
const heading = getByRole("heading");

// Find a textbox
const input = getByRole("textbox");
```

### With Name Option

```javascript
// Find button with specific text
const submitButton = getByRole("button", { name: "Submit" });

// Find heading with specific text
const mainHeading = getByRole("heading", { name: "Welcome" });

// Find textbox with label
const emailInput = getByRole("textbox", { name: "Email" });
```

### With State Options

```javascript
// Find checked checkbox
const checkedBox = getByRole("checkbox", { checked: true });

// Find selected radio button
const selectedRadio = getByRole("radio", { selected: true });

// Find pressed button
const pressedButton = getByRole("button", { pressed: true });
```

### With Level (for headings)

```javascript
// Find h1 element
const h1 = getByRole("heading", { level: 1 });

// Find h2 element
const h2 = getByRole("heading", { level: 2 });
```

### With Hidden Elements

```javascript
// Include hidden elements in search
const hiddenButton = getByRole("button", { hidden: true });
```

## Complete Test Examples

### Testing a Form

```javascript
import { render, screen } from "@testing-library/react";
import { LoginForm } from "./LoginForm";

test("renders login form with all elements", () => {
  render(<LoginForm />);

  // Find form elements by role
  const emailInput = screen.getByRole("textbox", { name: /email/i });
  const passwordInput = screen.getByRole("textbox", { name: /password/i });
  const submitButton = screen.getByRole("button", { name: /login/i });
  const form = screen.getByRole("form");

  expect(emailInput).toBeInTheDocument();
  expect(passwordInput).toBeInTheDocument();
  expect(submitButton).toBeInTheDocument();
  expect(form).toBeInTheDocument();
});
```

### Testing Navigation

```javascript
test("renders navigation with links", () => {
  render(<Navigation />);

  const homeLink = screen.getByRole("link", { name: /home/i });
  const aboutLink = screen.getByRole("link", { name: /about/i });
  const contactLink = screen.getByRole("link", { name: /contact/i });

  expect(homeLink).toHaveAttribute("href", "/");
  expect(aboutLink).toHaveAttribute("href", "/about");
  expect(contactLink).toHaveAttribute("href", "/contact");
});
```

### Testing Interactive Elements

```javascript
test("handles button clicks", async () => {
  const handleClick = jest.fn();
  render(<Button onClick={handleClick}>Click me</Button>);

  const button = screen.getByRole("button", { name: /click me/i });

  fireEvent.click(button);
  expect(handleClick).toHaveBeenCalledTimes(1);
});
```

## Best Practices

### 1. Use Specific Names When Possible

```javascript
// Good - specific and descriptive
const submitButton = getByRole("button", { name: "Submit Application" });

// Avoid - too generic
const button = getByRole("button");
```

### 2. Use Regular Expressions for Flexible Matching

```javascript
// Good - flexible matching
const loginButton = getByRole("button", { name: /log in/i });

// Good - partial matching
const emailInput = getByRole("textbox", { name: /email/i });
```

### 3. Combine with Other Queries When Needed

```javascript
// If multiple buttons exist, be more specific
const primaryButton = getByRole("button", { name: /primary/i });
const secondaryButton = getByRole("button", { name: /secondary/i });
```

### 4. Test Accessibility

```javascript
test("button has proper accessibility attributes", () => {
  render(<Button aria-label="Close dialog">×</Button>);

  const button = screen.getByRole("button", { name: /close dialog/i });
  expect(button).toHaveAttribute("aria-label", "Close dialog");
});
```

## Common Pitfalls

### 1. Elements Without Default Roles

```javascript
// Bad - div doesn't have a default role
const div = getByRole("div"); // This will fail

// Good - add role attribute
<div role="button">Click me</div>;
const button = getByRole("button", { name: /click me/i });
```

### 2. Hidden Elements

```javascript
// This will fail if element is hidden
const hiddenButton = getByRole("button", { name: "Hidden" });

// Use hidden option
const hiddenButton = getByRole("button", { name: "Hidden", hidden: true });
```

### 3. Multiple Elements with Same Role and Name

```javascript
// This will throw an error if multiple buttons have the same name
const button = getByRole("button", { name: "Save" });

// Use getAllByRole or be more specific
const saveButtons = screen.getAllByRole("button", { name: "Save" });
```

## Debugging Tips

### 1. Use screen.debug() to See Available Roles

```javascript
screen.debug(); // Shows all elements with their roles
```

### 2. Use screen.getByRole('') to See All Roles

```javascript

```

## Related Queries

- `getAllByRole` - Get multiple elements with the same role
- `queryByRole` - Returns null instead of throwing
- `findByRole` - Async version for elements that appear after a delay

## Advanced Usage

### Custom Roles

```javascript
// Define custom roles for complex components
<div role="tabpanel" aria-labelledby="tab-1">
  Content for tab 1
</div>;

const tabPanel = screen.getByRole("tabpanel", { name: /content for tab 1/i });
```

### ARIA Attributes

```javascript
// Elements with ARIA attributes
<button aria-expanded="false" aria-controls="menu">
  Menu
</button>;

const menuButton = screen.getByRole("button", {
  name: "Menu",
  expanded: false,
});
```

### Complex Form Controls

```javascript
// File input with custom styling
<input type="file" aria-label="Upload document" />;

const fileInput = screen.getByRole("button", { name: /upload document/i });
```

## Performance Considerations

### Efficient Queries

```javascript
// Good - specific and fast
const submitButton = screen.getByRole("button", { name: "Submit" });

// Avoid - too broad, slower
const allButtons = screen.getAllByRole("button");
const submitButton = allButtons.find((btn) => btn.textContent === "Submit");
```

### Memoization

```javascript
// For frequently accessed elements
const getSubmitButton = () => screen.getByRole("button", { name: "Submit" });

test("multiple interactions", () => {
  render(<Form />);

  const submitButton = getSubmitButton();
  // Use submitButton multiple times...
});
```

## Testing Patterns

### Page Object Pattern

```javascript
class LoginPage {
  constructor() {
    this.emailInput = () => screen.getByRole("textbox", { name: /email/i });
    this.passwordInput = () =>
      screen.getByRole("textbox", { name: /password/i });
    this.submitButton = () => screen.getByRole("button", { name: /login/i });
  }

  async login(email, password) {
    fireEvent.change(this.emailInput(), { target: { value: email } });
    fireEvent.change(this.passwordInput(), { target: { value: password } });
    fireEvent.click(this.submitButton());
  }
}
```

### Custom Render with Providers

```javascript
const renderWithProviders = (ui, options = {}) => {
  const AllTheProviders = ({ children }) => (
    <ThemeProvider theme={theme}>
      <AuthProvider>{children}</AuthProvider>
    </ThemeProvider>
  );

  return render(ui, { wrapper: AllTheProviders, ...options });
};

test("renders with theme", () => {
  renderWithProviders(<Button>Click me</Button>);
  const button = screen.getByRole("button", { name: /click me/i });
  expect(button).toHaveStyle("background-color: blue");
});
```
