## getByTitle(value, options)

return the elements that have the matching title attribute

# options

- exact:
  Use this when you want to ignore case or do partial matches.
- selector
  If multiple elements have the same title, you can target a specific tag.

- collapseWhiteSpace
  If the title contains irregular spacing or newlines, you can control whether spaces are “collapsed” during matching.
- normalizer
  You can pass a custom function that transforms the title text before matching.
  This gives complete control over how comparisons happen.
