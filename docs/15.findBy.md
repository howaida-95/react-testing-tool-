==> findBy/findAllBy
=====================
## findBy
return promise --> 
resolved: when element is found 
rejected: no element is found / more than one element is found (after default timeout = 1000ms )

## findAllBy 
return a promise ==> 
resolves: array of elements 
rejects: no element found

not shown now but after specific time
