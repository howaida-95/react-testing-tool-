We use MSW (mock server worker) in our tests to mock API calls at the network level.
The server is started once before all tests, 
reset after each test to avoid state leakage, 
and closed at the end to clean up resources.

🧪 Real example
test('loads users', async () => {
  render(<Users />);

  expect(await screen.findByText('John')).toBeInTheDocument();
});


Even though Users calls:

fetch('/users')


➡ MSW intercepts it
➡ Returns mocked data
➡ No real backend needed
