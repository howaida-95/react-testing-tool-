## query single elements

Single element queries return a single matching element and throw an error if multiple elements match.

- `getByRole('button')` - returns ONE button
- `getByText('Hello')` - returns ONE element with text "Hello"

## query multiple elements

When you need to query multiple elements that match the same criteria, use the **AllBy** variant of queries.

### AllBy Queries

All query types have an `AllBy` variant that returns an array of all matching elements:

- `getAllByRole()` - returns array of elements by role
- `getAllByText()` - returns array of elements by text content
- `getAllByLabelText()` - returns array of elements by label
- `getAllByPlaceholderText()` - returns array of elements by placeholder
- `getAllByAltText()` - returns array of elements by alt text
- `getAllByTitle()` - returns array of elements by title attribute
- `getAllByDisplayValue()` - returns array of elements by display value
- `getAllByTestId()` - returns array of elements by test ID

### Example Usage

```jsx
import { render, screen } from "@testing-library/react";

function TodoList() {
  return (
    <ul>
      <li>Buy groceries</li>
      <li>Walk the dog</li>
      <li>Finish homework</li>
    </ul>
  );
}

test("displays all todo items", () => {
  render(<TodoList />);

  const items = screen.getAllByRole("listitem");

  expect(items).toHaveLength(3);
  expect(items[0]).toHaveTextContent("Buy groceries");
  expect(items[1]).toHaveTextContent("Walk the dog");
  expect(items[2]).toHaveTextContent("Finish homework");
});
```

### Multiple Buttons Example

```jsx
function ActionButtons() {
  return (
    <div>
      <button>Delete</button>
      <button>Edit</button>
      <button>Save</button>
    </div>
  );
}

test("renders all action buttons", () => {
  render(<ActionButtons />);

  const buttons = screen.getAllByRole("button");

  expect(buttons).toHaveLength(3);
});
```

### Querying with Specific Criteria

You can combine `getAllBy` with query options to narrow down results:

```jsx
function UserList() {
  return (
    <div>
      <div role="article">
        <h2>John Doe</h2>
        <p>Developer</p>
      </div>
      <div role="article">
        <h2>Jane Smith</h2>
        <p>Designer</p>
      </div>
    </div>
  );
}

test("displays all user articles", () => {
  render(<UserList />);

  const articles = screen.getAllByRole("article");
  expect(articles).toHaveLength(2);

  const headings = screen.getAllByRole("heading", { level: 2 });
  expect(headings).toHaveLength(2);
  expect(headings[0]).toHaveTextContent("John Doe");
  expect(headings[1]).toHaveTextContent("Jane Smith");
});
```

### Key Points

1. **Returns Array**: `getAllBy` queries always return an array, even if only one element matches
2. **Throws on No Match**: If no elements match, `getAllBy` throws an error
3. **Array Methods**: You can use array methods like `.length`, `.map()`, `.forEach()` on results
4. **Indexing**: Access specific elements using array indexing: `items[0]`, `items[1]`, etc.

### When to Use Multiple Element Queries

- Testing lists (todo lists, navigation menus, etc.)
- Verifying multiple similar elements exist
- Checking the count of rendered items
- Iterating through elements to verify individual properties

### QueryAllBy and FindAllBy Variants

Just like single element queries, there are async and non-throwing variants:

- `queryAllByRole()` - returns empty array `[]` if no match (doesn't throw)
- `findAllByRole()` - async version that waits for elements to appear

```jsx
test("async multiple elements", async () => {
  render(<AsyncList />);

  // Wait for list items to appear
  const items = await screen.findAllByRole("listitem");
  expect(items).toHaveLength(5);
});

test("check if elements do not exist", () => {
  render(<EmptyList />);

  // Returns empty array instead of throwing
  const items = screen.queryAllByRole("listitem");
  expect(items).toHaveLength(0);
});
```
