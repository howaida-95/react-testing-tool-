## lower level pointer apis

- pointer({keys: "MouseLeft"})
- pointer({keys: "[MouseLeft] [MouseRight]"})
- pointer("[MouseLeft] [MouseRight]") ==> pass string in case keys is the only arg in func
- pointer({keys: "[MouseLeft>]"}) ==> press the button without release
- pointer({keys: "[/MouseLeft]"}) ==> release pressed button
